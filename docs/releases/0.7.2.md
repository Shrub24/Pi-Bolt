Pi-Bolt 0.7.2 runs Pi 1.1.0, up from 1.0.4, and carries no Pi-Bolt changes of its own.

### Pi 1.1.0

Everything in Pi [1.1.0](https://github.com/earendil-works/pi/releases/tag/v1.1.0), among it:

- **Program status in the terminal.** A terminal that speaks OSC 7501, and the agent dashboards that read it, see whether Pi is working, blocked on a dialog or a sign-in, done, or failed. `PI_PROGRAM_STATUS=1|0` overrides the detection found by querying the terminal.
- `--tools` and `--exclude-tools` take `+name` and `-name` entries, which change the default selection instead of replacing it (`pi-bolt -t +codemode,-write`).
- Claude Haiku 5.5, OpenAI's GPT-6 Luna as a classifier through the Decisions API, whose `models.classify()` context now accepts images, and llama.cpp 0.6.0 decision models listed as classifiers rather than chat models.
- A tool's execution time is recorded, as `durationMs` in the render context and in `tool_execution_end`, and `agent_settled` says whether a run was cancelled or finished.
- Fixes for managed installs keeping every old release, `.env` files in the launch directory reaching Pi's environment, images dropped as "could not be resized" under `node --watch` on Node 24.19+, paste in Termux, `/mcp` waiting for every server before opening, MCP sign-ins that could not be cancelled once the authorization server was slow, the fullscreen text selection surviving a session switch, provider "at capacity" errors ending a turn instead of being retried, and session costs undercounting long prompts on models priced by prompt length.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

or `pi-bolt update`, or `npm install -g pi-bolt`. The installer detects Linux or macOS by itself.

| Asset | For |
|---|---|
| `pi-bolt-linux-x64.tar.xz` / `.tar.gz` | **Recommended on Linux.** CPUs with AVX2 (Intel Haswell 2013+, AMD Zen+). |
| `pi-bolt-linux-x64-baseline.tar.xz` / `.tar.gz` | Any x86-64 CPU with SSE4.2. |
| `pi-bolt-linux-x64-jit.tar.xz` / `.tar.gz` | JIT also on, for plugins loaded at run time. |
| `pi-bolt-darwin-arm64.tar.xz` / `.tar.gz` | **macOS.** Macs with Apple silicon, macOS 13 or later. |
| `pi-bolt-darwin-arm64-jit.tar.xz` / `.tar.gz` | macOS, JIT also on. |
| `pi-bolt-runtime-linux-x64.tar.gz`, `pi-bolt-runtime-darwin-arm64.tar.gz` | The Pi-Bolt Bun runtime, for compiling plugins in. |

Linux x86-64 with glibc 2.17 or later; macOS 13 or later on Apple silicon.
